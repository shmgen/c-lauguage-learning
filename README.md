# C Language Learning

This repository records my C language learning notes and practice programs.

## Learning path

The examples currently organized here cover:

- Basic input and output
- Character classification
- Conditions
- Loops
- Arrays
- Functions
- Introductory pointers
- Union examples

The following topics have reserved folders for future practice:

- Strings
- Structures
- Enumeration
- Dynamic memory
- File I/O
- Data structures
- Comprehensive projects

## Original practice archive

The `archive/original-practice/` directory preserves the original `.c` files, including code that was commented out during earlier practices. Those comments are part of the learning record.

The categorized files are cleaned runnable examples; the archive files are historical reference and review material.
