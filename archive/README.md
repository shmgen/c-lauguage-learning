# Original Practice Archive

This directory preserves the original C practice files from the local Visual Studio projects.

The commented-out code is intentional. It contains earlier exercises that were temporarily disabled while writing new code, so it is part of the learning record and remains useful for review.

The categorized folders contain cleaned, runnable examples. This archive keeps the original context, naming, comments, and experimentation history.

The empty `test2.c` file was not added because Git does not track empty files.
